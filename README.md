# Nightfall Duel

An original local two-player, web-playable cosmic peg-battle. It is inspired by the feel of classic peg games, but has its own name, visuals, and arena design.

## Play

Open `index.html` in a modern browser. Select one of ten arenas, then drag from the launch star and release to fire. Players alternate five orbits each. Gold pegs score double and violet warp pegs teleport the orbit into a fresh collision.

No build system or external packages are required.
